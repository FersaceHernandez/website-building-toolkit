# Related website skills

The workspace uses these skills when building, reviewing, and deploying sites:

- `higgsfield-websites` — full-stack website/app lifecycle workflows.
- `workers-best-practices` — Cloudflare Workers review and authoring guidance.
- `wrangler` — Cloudflare Workers, Pages, D1, R2, and deployment operations.
- `browser-qa` — visual, interaction, accessibility, and smoke testing.
- `web-perf` — Core Web Vitals and network-performance audits.
- `production-audit` — local-evidence release readiness checks.
- `turnstile-spin` — end-to-end bot protection setup when requested.
- `brand-voice` — source-derived copy and voice consistency.
- `cinematic-hero.skill` — reusable cinematic hero composition workflow included in this repository.

Those operator skills are installed in the local environment and are referenced by name rather than copied into this public repository. Only `cinematic-hero.skill` is included here.
